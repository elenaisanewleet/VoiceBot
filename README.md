# 139bot — говорите голосом, в чат уходит грамотный текст

Бот для Telegram, который позволяет **не печатать**: вы говорите, а в переписке
с любым человеком появляется обычное текстовое сообщение — уже с пунктуацией,
без «э-э», оговорок и повторов.

Голосовые сообщения при этом никто не отправляет и не слушает. Собеседник
видит просто текст от вас.

## Как это выглядит

1. В любом чате наберите `@ваш_бот` — прямо в поле ввода.
2. Над клавиатурой появится кнопка **🎙 Говорить** — нажмите.
3. Говорите. Текст пишется на глазах, фраза за фразой.
4. **Отправить** — сообщение уходит в этот же чат обычным текстом от вашего имени.

Бота не нужно добавлять в чат, права ему не нужны, собеседник ничего не
настраивает и вообще ничего не замечает — сообщение приходит от вас.

## Почему устроено именно так

У Telegram-бота **нет доступа к микрофону** — ни у одного бота его нет, это
ограничение платформы. Микрофон доступен только веб-странице, открытой внутри
Telegram, то есть Mini App.

Поэтому связка такая:

```
@бот в любом чате
   └─ inline-режим отдаёт кнопку с Mini App
        └─ Mini App берёт микрофон, режет речь на фразы по паузам
             └─ сервер: распознавание → редактура (пунктуация, чистка речи)
                  └─ answerWebAppQuery кладёт готовый текст
                     ровно в тот чат, откуда всё началось
```

Ключевая деталь: Mini App, открытый **из inline-режима**, получает от Telegram
`query_id`. Только с ним бот может отправить сообщение в исходный чат от имени
пользователя. Если открыть Mini App иначе (например, кнопкой в личке с ботом),
`query_id` не будет — тогда приложение честно предложит выбрать чат.

## Бесплатный хостинг на Vercel (без карты)

Чтобы бот работал сам по себе, а не только при включённом ноутбуке. Ничего
устанавливать не нужно — всё делается в браузере, карта не требуется.

1. Заведите бота у **@BotFather**: `/newbot` → имя → адрес (адрес обязан
   начинаться с буквы и заканчиваться на `bot`). Сохраните токен. Затем
   **`/setinline`** — без него `@бот` в чужих чатах не появится.
2. Возьмите ключ распознавания на [console.groq.com/keys](https://console.groq.com/keys)
   (вход по почте, карта не спрашивается).
3. На [vercel.com](https://vercel.com) войдите через GitHub → **Add New → Project**
   → импортируйте этот репозиторий.
4. В **Environment Variables** добавьте:

   | Переменная     | Значение                            |
   | -------------- | ----------------------------------- |
   | `BOT_TOKEN`    | токен из шага 1                     |
   | `STT_API_KEY`  | ключ из шага 2                      |
   | `USE_WEBHOOK`  | `true`                              |
   | `STT_BASE_URL` | `https://api.groq.com/openai/v1`    |
   | `STT_MODEL`    | `whisper-large-v3-turbo`            |
   | `LLM_MODEL`    | `openai/gpt-oss-120b`               |
   | `DEFAULT_LANG` | `ru`                                |

5. **Deploy**, дождитесь окончания сборки.
6. Один раз откройте в браузере `https://ваш-проект.vercel.app/api/setup` —
   это привязывает бота к адресу. Страница ответит «Готово» и назовёт бота.

Адрес проекта подставляется сам (`VERCEL_PROJECT_PRODUCTION_URL`), вписывать
`PUBLIC_URL` не нужно. Бессерверные функции не засыпают, поэтому `KEEPALIVE`
здесь не нужен.

Как это устроено: `public/` Vercel раздаёт статикой, а всё под `/api/`
(включая вебхук) уходит в одну функцию `api/[...path].js` — она передаёт запрос
в тот же обработчик, что и обычный сервер. Отдельной ветки кода под хостинг нет.

### Альтернатива: Render

В репозитории лежит и `render.yaml` — Blueprint для [render.com](https://render.com)
с бесплатным планом, вебхуком и защитой от засыпания (`KEEPALIVE`: бесплатный
инстанс засыпает после 15 минут тишины и просыпается почти минуту, поэтому
сервис раз в 10 минут дёргает собственный `/health`). Учтите: **Render теперь
просит привязать карту** даже на бесплатном плане — если карты нет, идите
на Vercel.

## Быстрый старт на macOS (без карты)

Три команды в Терминале — и бот работает с вашего ноутбука.

**Что понадобится.** Node.js и cloudflared (им поднимается https-туннель, без
него Telegram не откроет Mini App):

```bash
brew install node cloudflared
```

Если Homebrew ещё не стоит — одна строка для установки на [brew.sh](https://brew.sh).

**Дальше:**

```bash
git clone https://github.com/smmsemmers/139bot.git
cd 139bot
npm run setup     # спросит токен, ключ и язык, всё проверит и запишет .env
npm run dev       # поднимет туннель и запустит бота
```

`npm install` не нужен — у проекта нет зависимостей.

**Про ключ без карты.** В `npm run setup` первым вариантом идёт
[Groq](https://console.groq.com/keys): регистрация по почте, карта не
запрашивается, бесплатного тарифа хватает с запасом. Там же используется
`whisper-large-v3-turbo` для распознавания и `openai/gpt-oss-120b` для
редактуры. Захотите сменить — это одна строка в `.env`, код провайдер-независим,
подойдёт любой OpenAI-совместимый адрес, включая локальный whisper.cpp.

**Один раз в @BotFather:** `/newbot`, затем **`/setinline`** — без включённого
inline-режима `@бот` в чужих чатах не появится.

**Пара честных мелочей про локальный запуск.** Пока команда `npm run dev`
работает — работает и бот; закрыли Терминал или усыпили ноутбук — бот
недоступен. Адрес туннеля меняется при каждом запуске, поэтому `npm run dev`
сам переписывает его в `.env`. И если провайдер режет Telegram, понадобится
VPN — бот об этом скажет прямым текстом, а не номером ошибки.

## Установка на сервер

### 1. Бот в @BotFather

```
/newbot            → получите BOT_TOKEN
/setinline         → выберите бота, задайте подсказку, например: «Говорите — превращу в текст»
```

`/setinline` обязателен: без включённого inline-режима `@бот` в чужих чатах
работать не будет. Это единственная разовая настройка.

### 2. Переменные окружения

```bash
npm run setup     # либо вручную: cp .env.example .env
```

Минимум, который нужно заполнить:

| Переменная    | Что это                                                        |
| ------------- | -------------------------------------------------------------- |
| `BOT_TOKEN`   | токен от @BotFather                                              |
| `PUBLIC_URL`  | **https**-адрес, на котором открыт сервер                        |
| `STT_API_KEY` | ключ к распознаванию речи (по умолчанию — OpenAI-совместимое API) |

`PUBLIC_URL` обязан быть `https://`: Telegram не откроет Mini App по `http`,
и браузер не даст микрофон незащищённой странице.

### 3. Запуск

```bash
npm start
```

Зависимостей нет — только Node.js 20.11+. `npm install` не нужен.

Для запуска с ноутбука есть `npm run dev` — она сама поднимает https-туннель и
подставляет адрес (см. быстрый старт выше).

В Docker:

```bash
docker build -t 139bot . && docker run --env-file .env -p 8080:8080 139bot
```

По умолчанию бот работает через long polling. Для продакшена поставьте
`USE_WEBHOOK=true` — вебхук встанет на `PUBLIC_URL/webhook/<секрет>` сам.

## Настройки внутри приложения

- **Стиль** — `как сказано` (сырая расшифровка), `грамотно` (по умолчанию:
  пунктуация, чистка речи, исправленные окончания), `по-деловому` (нейтральный
  письменный тон).
- **Язык** — конкретный язык распознаётся заметно точнее, чем «определить сам».
- **Отправлять сразу после паузы** — договорили, помолчали полторы секунды,
  сообщение ушло. Руки вообще не нужны.

Текст перед отправкой можно поправить руками — он лежит в обычном поле ввода.

## Что ещё умеет

- Пришлите боту **голосовое, аудио или кружок** в личку — вернёт расшифровку с
  кнопкой «📨 Отправить в чат».
- `@бот` без текста показывает последние распознанные фразы — можно отправить
  повторно, в другой чат.

## Честные ограничения

- **Одно сообщение за одно открытие.** `query_id` одноразовый: после отправки
  Telegram закрывает Mini App. Для следующей реплики — снова `@бот` и кнопка.
  Это ограничение Telegram, обойти его нельзя.
- **Разрешение на микрофон** Telegram спрашивает один раз — у системы. Если
  случайно отказали, включать придётся в настройках телефона.
- **Распознавание идёт на сервере**, куда указывает `STT_BASE_URL`. Расшифровки
  нигде не сохраняются: последние фразы живут в памяти процесса час и исчезают
  при перезапуске.
- В группах без inline-режима у бота (если владелец группы запретил inline)
  кнопка не появится — но это редкость.

## Когда проще без бота

Системная клавиатура на телефоне тоже умеет диктовать — но она пишет ровно то,
что вы сказали, вместе с «ну», «э-э» и оговорками. Смысл этого бота именно в
том, что между микрофоном и чатом стоит редактура: получается текст, который не
стыдно отправить.

## Разработка

```bash
npm test       # 30 тестов: подпись initData, ручки API, хранилище, разбор mime, чистка ответа модели
npm run watch  # автоперезапуск без туннеля
```

Структура:

```
api/
  [...path].js  переходник для бессерверных площадок: тот же обработчик
scripts/
  setup.mjs     интерактивная настройка .env с проверкой токена и ключа
  dev.mjs       https-туннель + запуск бота одной командой
src/
  index.js      запуск: сервер + polling/webhook
  server.js     HTTP: раздача Mini App и ручки /api/*
  bot.js        обработка апдейтов: inline-режим, личка, голосовые
  stt.js        речь → текст → грамотный текст
  initData.js   проверка подписи Telegram (без неё можно было бы писать от чужого имени)
  telegram.js   клиент Bot API
  store.js      последние фразы, в памяти, с TTL
public/
  index.html    Mini App
  app.js        микрофон, нарезка по паузам, отправка
  style.css     тема подхватывается из Telegram
```
